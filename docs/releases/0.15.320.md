# RelionDeLuxe 0.15.320 — initial public prerelease

Browser-based SPA/STA interface for RELION, including job preparation and continuation, Feed and Hierarchy views, conditional next-job suggestions, CTF and LoG previews, map viewers, tomography helpers, and workstation/cluster configuration.

This release includes the application source, tests, installation and configuration guides, GPL-2.0-or-later license, and third-party notices. It does not bundle RELION, compiled adapters, or scientific project data.

## Installation

Extract `RelionDeLuxe-0.15.320.zip`, enter the extracted directory, and run `sh scripts/start.sh --demo` with Node.js 22 or newer. Real processing requires the matching RELION installation and a compiled adapter; see `docs/installation.md`.

## Validation and known limitations

**Prerelease: known test failures remain.** The local Linux/Node.js 24.22.3 run completed with 601 tests: 553 passed, 13 failed, and 35 skipped. See `docs/repository-validation.md` for the failing tests and the repository Actions tab for Node.js 22 CI results. Native integration, cluster execution, scientific acceptance and interactive browser acceptance remain unverified. The release archive is a source distribution, not a declaration of production readiness.
