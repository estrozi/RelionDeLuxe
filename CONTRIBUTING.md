# Contributing

Describe the affected job type, SPA/STA mode, RELION version, RelionDeLuxe version, operating environment and steps to reproduce. Remove project identifiers and token URLs from shared logs. For interface changes, include the relevant browser and theme.

Keep native RELION interoperability and existing project formats intact. Run `npm test`; document native integration or scientific tests separately. See docs/repository-validation.md for the current baseline. Keep unrelated changes out of patches and preserve upstream license notices.
